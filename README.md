# Ivan Viakhirev — personal website

Live site: https://6ovnavi.github.io/

Static HTML, CSS and JavaScript. No build, package installation, API keys or backend required.

## Preview

Open `index.html` in a browser, or run `python -m http.server 8000` in this folder.

## Update

Edit `index.html`, commit and push to `main`. GitHub Pages publishes from the repository root.

Research topics are kept on the site; the publication list links to Google Scholar.
Animations respect reduced motion and have pause controls. Offscreen simulations are suspended.
